# 0.3.2 公开发布说明

## 版本定位

0.3.2 是 HearthCrew 的公开开发快照，重点修复了三类长期影响自主执行的问题：

1. 移动目标只按水平接近被误报完成。
2. 采集需要开路时，工具层没有把有限开路能力暴露给决策层。
3. 受阻阶段、旧失败状态和重复扫描会把伙伴错误地推入无计划或永久等待。

## 本版变化

- 新增精确移动完成核验：目标高度、实际脚位和连续落地都必须满足。
- 新增 `EXCAVATE` 有界动作；破坏预算、保护区、液体和危险限制继续生效。
- 受阻阶段进入结构化等待，保留长期目标并允许一次有依据的重新评估。
- 历史动作与当前执行权分离，迟到回执不能复活终态动作。
- 0.3.1 相关旧阻塞状态只做一次保守重新评估，不重放世界修改。
- 抑制由旧 Numen MCP 心跳产生的误导性黄色提示，同时保留真实控制器连接状态。
- H 面板支持小队、Ember、Moss、Flint 定向任务发送。

## 验证边界

本版通过了对应的控制器、Java 和隔离 GameTest 检查。未启动用户客户端、未调用真实 Luna 做自动验收，也未把私人存档作为测试夹具。真实长期自主行动仍需要用户从 PCL 手动验证。
