# HearthCrew 0.3.3 开发版

Ember、Moss、Flint 改用 `gpt-6-luna / high`，保留三个独立会话、目标与记忆。专用 Codex CLI 固定为 `0.158.0-alpha.2.1`；模型目录、能力探针、诊断、H 提示词和版本字段同步更新。实际模型或推理等级不符时拒绝启动，不回退 GPT-5.6。

本次另修复阻止与长明共存加载的重生注入冲突。旧实现和长明都重定向 `PlayerList.respawn` 的构造入口；现改为在原版恢复库存、注册新身体之前修改新身体局部变量。仅转换 HearthCrew 已拥有的 Numen 伙伴，其余构造结果保留；注入仍要求成功，不用可选注入掩盖失效。生存执行算法、协议6及固定 Numen 依赖不变。

## 安装与回退

通过上述针对性门槛后，在Minecraft退出时安装唯一的0.3.3 JAR及固定执行库，更新专用CLI启动路径和已编译控制器。保留长明、其他Mod、存档、认证及伙伴历史。具体提交、哈希、安装前清单、备份和控制器状态写入本机忽略目录的安装记录。

回退前退出Minecraft并停止本项目控制器；按安装记录移除本次新增的两个JAR，恢复备份的启动配置和控制器文件。此前实例中没有HearthCrew和执行库，不应据此删除其他Mod或伙伴存档。
