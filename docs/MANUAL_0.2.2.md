# 0.2.2 PCL 手测清单

直接用 PCL 启动原来的 NeoForge 1.21.1 实例；不用删档。H → 加入伙伴可补齐缺少的角色，再在设置确认自主开启。

1. 附近有树时，让伙伴采一批木头：一棵不够应继续找同范围合格树，而非宣称无木材。
2. 让有镐的伙伴“采8块石头”：应持续采掘并拾取，整批结束才汇报。没有通路应说明需要开路，不反复挖已消失的位置。
3. 观察台阶和工作台接近：在目标高度站稳才报告到达；受阻原因能在H查看。
4. 查看背包与H待回收记录：破坏数和实际物品数分别记录；满包或掉落未取得不能报告已拿到全部物品。
5. 观察有条件的浅水上岸和乘船：真正到岸、实际生成一条船并登船才算相应动作成功。
6. 玩家发问、普通任务和暂停/恢复后，检查三个独立会话是否继续各自工作，聊天是否仍按阶段汇报。退出重进后检查无重复物品/施工。

如果再次停住，保留存档，记录大致时间、伙伴名字和H诊断信息即可；原始运行日志会留在本机用于复盘。这是开发版，自动检查尚不代表真实陪玩验收通过。
