# HearthCrew 0.3.2 公开状态

这是公开仓库使用的脱敏状态摘要。它不包含个人存档、控制器令牌、原始模型对话、运行日志或本机安装路径。

## 已完成的工程部分

- NeoForge 1.21.1 / 21.1.249 模组工程和 Java 21 构建链。
- ServerPlayer 伙伴身份、保存、重连、死亡、重生和维度核对。
- Numen 玩家身体适配层与 HearthCrew 单一执行权。
- TypeScript 控制器、五个游戏工具、协议握手和本地 pairing。
- 连续资源任务、有限准备、有限开路、真实拾取证据和任务恢复。
- 原版配方、工作台、容器和熔炉的受控交互。
- H 菜单、任务总览、真实对话、背包摘要和定向玩家任务。
- 精确移动完成核验、迟到调用拒绝、旧回合隔离和结构化等待条件。

- 控制器和协议回归：通过。
- Java 核心与生产构建：通过。
