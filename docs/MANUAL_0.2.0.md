# 0.2.0 新存档试玩

从 PCL 启动 1.21.1-NeoForge_21.1.249，创建新的普通生存世界。三名空背包伙伴自动初始化。旧存档无需删除。

1. H → 诊断查看控制器、三个不同会话和实际 Luna/high。离线时点“启动控制器”，稍等后刷新。继续使用专用 Codex 登录，不向伙伴提供密码。
2. 开启自主模式，让三人选择采集、探索和制作。背包仍区分快捷栏和主背包，以实际库存为准。
3. T 栏 `@Ember 你准备做什么？` 是交流；`@小队 帮我准备食物` 是普通请求，会排在当前自主工作后。明确“立即停止当前任务，改为……”才紧急改派。
4. 伙伴按阶段汇报，逐块不刷聊天。若静止，查看动作、等待条件和模型状态，记下伙伴名字与时间方便日志复盘。
5. 玩家容器需要近处执行 `/hearthcrew public x y z` 标记公共。伙伴自建容器自动共享；投料不等于已经取得产物。
6. 原版名字命令：`/tp Ember`、`/tp Ember ~ ~ ~`、`/kill Moss`、`/give Flint minecraft:iron_pickaxe`。仍遵守原版权限，未开启作弊不能使用管理命令。
7. H 暂停/急停，或 `/hearthcrew standby`、`/hearthcrew autonomy on|off` 控制小队。不必重复启动控制器。

建议重点观察主动寻找木材/食物、连续制作采集、下水决策、遇敌反应和重生后重新决策。关闭游戏后提供时间即可查看本机日志，不用逐条抄聊天。

开发版未完成真实陪玩验收。详细能力及未验证范围见 `RELEASE_0.2.0.md`。
