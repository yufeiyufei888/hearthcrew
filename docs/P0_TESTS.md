# HearthCrew P0 GameTest contract

`CompanionP0GameTests` uses the original `p0_empty` structure fixture. Each test builds only its own five by five stone floor and places its own entities or blocks, so a test result is tied to observed server state rather than a shadow inventory.

The suite covers movement around an obstacle, real tool mining with the drop entering `CompanionEntity.inventory()` and a completed action receipt, item pickup into the actual inventory, an edge-distance pickup that requires body contact, timed food use, ordinary living damage, armor durability damage, player-style inventory settlement under both `keepInventory` values with `doMobLoot=false`, common hostile target eligibility, bed and Nether-anchor respawn selection, and persistence of the companion identity, owner, inventory, and food state. The sleep case requires actual bed occupancy and then checks identity and inventory across lethal damage and automatic bed respawn. The food gate also restores the serialized food and peaceful timers and observes natural regeneration. Dragon damage and breath tests use a normal ticking dragon in `SITTING_FLAMING`; only the phase and test platform are controlled. Portal gates use valid, test-built Nether frames and ordinary End portal blocks; they exercise the entity's native portal processor and dimension replacement, including physical exit from the arrival portal before the order is completed.

The fixture and test source are implementation inputs, not pass evidence. On 2026-09-05, the initial 13-test NeoForge 21.1.249 server run passed (`.artifacts/testlogs/gametest-20260905-120631.log`), and the first expanded 15-test run passed (`.artifacts/testlogs/gametest-expanded-20260905-121008.log`). The 18-test run at `.artifacts/testlogs/gametest-portals-20260905-122413.log` had 14 passes and four required failures before the latest production fixes. The intermediate combined run at `.artifacts/testlogs/gametest-final-20260905-123234.log` passed all kernel tests and 18 of 20 GameTests. The final combined `:kernel:test` plus server run at `.artifacts/testlogs/gametest-diagnostic2-20260905-123557.log` passed all kernel tests and all 23 required GameTests. This includes real dragon damage and breath injury, mining pickup, armor durability, food timers, Nether round trip, End entry/exit, body control, and the original P0 gates. The portal fixtures build a complete frame before filling portal blocks, use `AXIS.X`, provide solid source/destination platforms, keep destination chunks ticking, and require physical portal exit before completion. A raw-NBT fixture previously failed before execution; `p0_empty.nbt` is now deterministic GZIP. These tests remain P0 server gates and do not establish campaign or soak evidence; the separate P0Visual client screenshot is reported as visual evidence elsewhere.
