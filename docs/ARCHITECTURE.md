# HearthCrew 架构与实施约束

本文件落实用户批准的炉火伙伴方案；阶段结果以 STATUS.md 和测试证据为准。

## 产品与平台

Windows、Minecraft 1.21.1、NeoForge 21.1.249、Java 21；首发三个独立性格和记忆的伙伴，使用独立 Codex 会话，目标配置 gpt-5.6-luna / high。fast 必须先验证接口和账户能力，界面展示服务端实际返回的设置。专用 App Server 与桌面使用的全局配置隔离。

首发环境为单人集成服务器，与 JEI、Jade、AppleSkin、Mouse Tweaks、Neat、Xaero 小地图做实际兼容测试。公网服务器、全成就、所有内容模组和语音不在首发验收范围。

用户使用 PCL（Plain Craft Launcher 2）启动 Minecraft，并允许开发测试使用独立启动方式。开发阶段使用仓库内 NeoForge 实例；交付前需在独立 PCL 配置中验证安装和启动，保留用户现有实例与存档。

## 控制与执行

固定链路：桌面 MCP / 游戏界面 → 本地控制器 → Mod 仲裁器 → 三个身体。

每个身体是自定义 PathfinderMob。模型不能直接修改实体、背包或世界。需要玩家上下文的方块交互借用受限 FakePlayer；FakePlayer 不拥有独立资源副本，不注册为第四名伙伴，也不承担导航。

模型提交长期目标和复合动作，服务端按 tick 持续执行。移动、伤害、物品消耗、掉落和传送门使用游戏实际机制。优先级为急停、即时求生、护卫、玩家命令、团队任务、补给、个人活动。低优先级活动不能覆盖已有任务。抢占必须保存足够的局部进度；恢复之前观察并验证条件。

动作结果区分接受、运行、完成、部分完成、失败、取消，以及必须核对的过期/失效状态。模型超时不终止健康身体动作。采集必须验证实际入包，建造必须验证方块与消耗，旅行必须验证实际位置与维度。重复调用不能再次产生世界效果；不明结果不能通过重放、库存回滚或补发物品消除。

## 身体规则

36 格背包、盔甲与副手；真实装备耐久和食物消耗；独立饥饿、饱和度、消耗度与再生计时。死亡遵守 keepInventory、消失诅咒及实际物品掉落；重生选择有效床、充能锚或安全出生点。没有安全出生点时保留待恢复记录。

原版怪物对非玩家伙伴需显式适配目标选择，不能仅让模型说在护卫。末影龙伤害、目标选择、交易等玩家专属行为单独验证。传送门通过实际接触触发原版传送，导航不能用传送脱困。

## 连接与会话

控制器 TypeScript / Node.js 通过 stdio 驱动一个官方 App Server，建立三个独立角色会话。桌面 MCP 的 status / command / control / events 操作同一个小队。角色仅有 observe / propose_work / act / share / remember 游戏工具。

Mod 与控制器在 loopback 通信，使用带认证的 4 字节大端长度前缀 JSON，最大帧 1 MiB。读取、写入和重连在独立线程进行；请求只能排入服务端线程，队列有上限。消息携带世界、会话、身体代次、任务、动作等标识；事件确认和重同步是协议组成部分。

独立配置目录通过官方登录认证，不复制桌面凭据。必须验证不继承其他插件、MCP、文件和命令工具。仅列出游戏动态工具或读取到关闭开关，不足以证明模型实际工具面受限；需契约与实际负例验证。

## 协作与保护

角色偏好分别为协调防卫、探索采集、建设后勤，基础技能完全共享。队长也必须执行实际工作。聊天协商要落实为服务端任务、资源预留和交接记录。个人长期记忆与公共任务/设施账本分开。

新命令、危险、任务结果和真正空闲触发思考。不得以重复轮询或定时闲聊伪造活跃。相同失败达到阈值后切换策略或明确缺少条件。

附近扫描默认 32 格，可包含隐藏资源，但不能读取世界种子或进行全图定位。探索采用有上限并随移动维护的区块加载，退出世界释放。游戏暂停冻结任务计时和租约。

玩家标记区域、已记录建筑与私人容器受保护，归属不明的建筑不自动拆改。公共箱需要明确标记；伙伴创建的公共设施默认共享。

## 发布门槛

P0 身体 → P1 单角色采木/制作/交付 → P2 三人基地与协作 → P3 主世界/下界/要塞/末地/龙战返程 → P4 完整实玩、故障、兼容、安装和长时间运行。各阶段通过后才扩大功能验收范围。

硬性指标：20 TPS 下主人遇袭 1 秒内开始本地护卫；已有可执行动作时不因调度遗漏空闲超过 15 秒；三人 30 分钟并发与 120 分钟稳定性；控制器/App Server 强杀恢复没有重复交接或建造；覆盖满包、缺料、工具损坏、遮挡、地下同坐标、卡住、死亡、暂停、维度和单角色失败。

至少一次全新普通生存世界通关，并在另一种子复验基地、探索与下界。正常验收不使用创造、传送、生成物品或修改目标状态。记录三名伙伴的实际贡献，不能把玩家独自完成关键工作视为 AI 通关。
